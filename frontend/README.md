# Nari Frontend (Static Demo)

This folder contains a minimal static login UI for demo purposes.

Open `index.html` in a browser to view the login page:

```bash
# macOS / Linux
open frontend/index.html

# or with a simple Python HTTP server
cd frontend && python3 -m http.server 8000
``` 

The form performs client-side validation and shows a demo success message. Replace the client code in `app.js` with real API calls for production.
